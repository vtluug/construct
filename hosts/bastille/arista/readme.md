# Pahoehoe 7050QX-32

```
Pāhoehoe (pronounced "pah-hoy-hoy") is a type of low-viscocity basaltic lava with a smooth, shiny, billowy, or ropy surface.
```

Pahoehoe acts as the cluster's backend network, supplying the blades with two bonded 10G SFP+ connections, and Vesuvius with a 40G QSFP+ link.

It is statically routed.
